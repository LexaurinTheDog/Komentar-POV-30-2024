# Komentář k zákonu č. 30/2024 Sb., o pojištění odpovědnosti z provozu vozidla

Odborný komentář k **zákonu č. 30/2024 Sb., o pojištění odpovědnosti z provozu vozidla (POV)** — nástupci zákona č. 168/1999 Sb., transponujícímu směrnici (EU) 2021/2118: povinnost pojištění vázaná na provoz vozidla včetně mikromobility, přímý nárok poškozeného, limity plnění, Česká kancelář pojistitelů, garanční fond a fond zábrany škod. Nový zákon — judikatura k němu dosud neexistuje; unijní linie SDEU (Vnuk, Torreiro, Andrade, Juliana) je doložena v místní důvodové zprávě.

Konsolidované znění: dokument e-Sbírky `SB-2024-00030_2025-07-01`.
